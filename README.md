# AI Stuff for Music Stuff
## AUtoSHEET
An audio to music sheet converter. Still not very accurate but can detect simple monophonic audio files.

## SHEETtoCHORD
An automatic music sheet chord detection. A rule based system based of theory music. Unfortunately, it is not very accurate. Will develop it for my Bachelor's thesis.

## SYNtoSHEET
Piano synthesia video to music sheet converter. Still work on progress.
